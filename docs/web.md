# Angelo — web-to-figma

- Pipeline, Figma and capture gotchas → `docs/web-gotchas.md`
- Front-end techniques (CSS, effects, stacking…) → `skill/web-to-figma/techniques.md` (index) + `techniques/<theme>.md`: every miss found by the check becomes a generic fix + a line in the catalogue + an expectation in `tests/web/<case>/expect.json`

## Commands

- URL → Figma: run `node tools/web-to-figma.mjs <url>` first (targets the open file by default, `--file <f>` otherwise): the frame appears in Figma in ~1 s, then capture → fonts → `web-build --root`
- `tools/web-capture.mjs` (puppeteer from the npx cache, data only) → structured build `tests/web/<case>/build.mjs` on `tools/web-lib.mjs` (Lucide, local `loadImages`) · `tools/web-build.mjs` = flat reference frame only · `<case>` = `caseName(host)` from `web-lib`: host without `www.` or TLD, labels joined by `-` (`example.com` → `example`, `docs.example.com` → `docs-example`)
- Check after every build: `node tools/web-compare.mjs <case> --file <f> --root <id>` (run by `web-to-figma`) → gaps per named block + stacked texts in Figma (ids) + `compare-*.jpg` page | Figma | gaps + the **element contract** (every image / svg / text of the capture is present in Figma at its place, realigned ±12 px: absent, empty, other image, differs, shifted; `elements-1.jpg` worst first; a suspect reference = texts with no ink on `page.jpg`) + `tests/web/iso.csv`; `--fix` (passed by `web-to-figma`) places missing / empty images again, then re-checks · fix in `tools/web-*`, then rebuild
- Mobile version: `node tools/web-to-figma.mjs <url> --width 430`, or turn the plugin's `mobile` switch on before pasting the URL (the extension captures the tab at its own width, the switch does not touch it) · the site as served to a phone (`isMobile` viewport + touch + iPhone Safari user agent, DPR 1, height 932), not the desktop layout shrunk · frame `<host> · 430`, folder `tests/web/<case>-430`, check images at full size under 800 px (the desktop ones are at half size) · `--part` works the same way (the `--home` frame must be named `<host> · 430`) · in the extension, picked blocks + the both / mobile button → the same blocks at 430 (`--part`; a name not found at 430 is reported as a failure, never a whole-page fallback)
- A single section, headless: `node tools/web-capture.mjs <url> <out> --blocks` lists the blocks (a repeated name becomes `Name#2`); `node tools/web-to-figma.mjs <url> --part "A + B"` redoes a section or sub-section in a staging frame `<host> · <part>`, then puts it in place of the old one inside the full-page frame named after the host (`--home` otherwise) · the case's `capture.json` / `page.jpg` become the section's (`page.jpg` stays the whole page; the capture's holes drop the rest)
- `npm run web-check` → the `tests/web/<case>/` corpus, outside Figma; rerun after any change to `tools/web-*`
- `node tools/web-core-check.mjs` → `plugin/dist/web-core.js` (full build without Node, `tools/web-run.mjs`; `web-build.mjs` is the Node host) = same tree and same execs as `tools/` on the whole corpus, fake plugin, after `npm run build`
- `node tools/web-boards.mjs` → arranges the "Components" page (one board per site ≤ 4000 px in wrapping rows, a set's variants on one row, wrapping beyond 3840 px, boards side by side); `web-build` arranges only the board it touches
- Chrome extension `extension/` (MV3, `debugger` permission = full-page `page.jpg` capture, POST `/capture`)
- Live test of a crop of a `.angelo.json` capture (without redoing the page): a script outside the repo = `runBuild({ cap, rpc: makeRpc("<Figma file name>"), images: dataImages })` · `makeRpc` takes the open file's name (plugin ping), not a path · keep the ancestors of every kept box (otherwise `layoutTree` crashes, root missing) · a photo over ~400 KB should be reduced (`sips -Z`): `/rpc` refuses an exec > 1 MB, the plugin does not · the plugin's import status = steps joined by ` · `, no final "ok" · cleanup: remove the frame + board after checking that no instance elsewhere depends on them
- Pasting in the plugin: click the selection line → paste a URL → the bridge runs `web-to-figma` on the open file (`ROUTES` entry in `server.mjs`, one job at a time, stdout shown in the plugin, any other text refused)
